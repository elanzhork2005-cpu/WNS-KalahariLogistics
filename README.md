Project Summary 
This project presents a wireless and WAN network design for Kalahari Logistics Ltd. The simulated network connects the Windhoek headquarters with a Walvis Bay branch, a Johannesburg SADC partner office, and a London global data centre. Cisco Packet Tracer is used to demonstrate the network topology, IP addressing, wireless connectivity and WAN communication between the sites.
